## Ownership principle

Everyone should contribute to analysis/code and interpretation/writing in
an equitable way. Use real GitHub handles only after members provide them.
Record completed work in [contributions.md](contributions.md), not by
changing proposed leads into claims about authorship.

## Board conventions

Status values: To decide → Pending → In progress → Review → Done.
Add a commit, pull request or output link when a task moves to Done.
New tasks can use the repository's issue template; existing rows remain
the lightweight board unless the group deliberately sets up GitHub Projects.
