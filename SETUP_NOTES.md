# Setup notes

This repository scaffold was generated from the supplied course outline,
group topic statement, latest annotated notebook and its saved results.

The setup script only creates local files. It does not create a GitHub
account/repository, push commits, open issues or a Projects board, invite
teammates, submit to CourseLink, or run a new data analysis.

If an existing file differs, the script preserves it and prints its path.
Review and merge documentation deliberately; use `docs/project_home.md`
if an existing root README was preserved. Re-running the setup is safe and
does not overwrite the group's subsequent edits.

The notebook included in the script is the version prepared for the group
in the conversation. If a more recent notebook exists in the actual GitHub
repository, keep the newer work and review differences rather than replacing
it with this embedded baseline.

Sources inspected: course outline pp. 4–8; topic statement pp. 1–3;
current annotated notebook; supplied Destiny sample CSV; publisher dataset
metadata. Source spreadsheets are not bundled and no fresh full run is
claimed. AI-process and contribution records remain for group completion.
