# Working notebook

[Steam_Reviews_D2_VS_Warframe.ipynb](Steam_Reviews_D2_VS_Warframe.ipynb) is the shared analysis notebook for both games.

[Open it in Google Colab](https://colab.research.google.com/github/kenzomiller11-dotcom/CTS2KSteamGroup/blob/main/notebooks/Steam_Reviews_D2_VS_Warframe.ipynb).

## Run it

1. Have both original spreadsheets from [data/raw/](../data/raw/) available on your computer.
2. Open the notebook in Colab.
3. Run the upload cell and select both spreadsheets.
4. Run the remaining cells from top to bottom.
5. Upload the downloaded game CSVs to [outputs/](../outputs/), keeping their existing filenames.
6. Save the updated notebook back to this location in GitHub.

The notebook uses Colab's upload/download tools. It does not automatically read files from this repository or save results back to GitHub.

The notebook's code, samples and saved outputs were preserved during repository organization.
