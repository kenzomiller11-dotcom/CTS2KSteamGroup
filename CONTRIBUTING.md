# Contributing

## One clear task at a time

1. Choose a task from [the board](docs/task_board.md) and agree on ownership.
2. Create a short branch such as `data/verify-counts` or `paper/methods`.
3. Make a small change and add explanations someone else can understand.
4. Check the relevant output and open a pull request describing the change.
5. Ask a groupmate to review it; record decisions and real contributions.

Branch names are suggestions. Work under your own account, and attribute
collaborations accurately. Do not rewrite history to create fake earlier
activity or claim another member completed work they have not confirmed.

## Notebook collaboration

- Coordinate before editing the same notebook at the same time.
- Keep `notebooks/Steam_Reviews_D2_VS_Warframe.ipynb` as the working analysis.
- Preserve clear comments and meaningful outputs.
- Make methodological changes explicitly and explain their effect on results.
- Recheck manual label order if the data or sampled examples change.
- Distinguish a saved-output inspection from a complete rerun on source data.

## Writing and records

Everyone should help with interpretation, writing and understandable code.
Add real completed work to [contributions](docs/contributions.md), discuss
intermediate results in [check-ins](docs/check_ins.md), and record AI use in
[the process log](docs/ai_usage.md). The paper should read as a shared work.
